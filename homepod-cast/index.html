4

四声道Quad*

前后环绕，多台同步

Front and rear, all in sync

* 独立的后置声道需要把 Windows 输出设备配置成 5.1 或 7.1。音源是立体声时，后置会重复前置。

* Separate rear channels need a 5.1 or 7.1 Windows output device. With a stereo source the rear speakers repeat the front ones.

上手Get started

3 步用起来

Three steps to sound

  1. 运行 HomePodCast.exe

    Run HomePodCast.exe

    单个文件，无需安装、账号或驱动。

    A single file. No install, account or driver.

  2. 选择布局，再为每个声道指定一台 HomePod

    Pick a layout, then a HomePod for each channel

    分不清哪台是哪台？点 ♪ 让那台音箱响一声。

    Not sure which is which? ♪ plays a short test sound on that speaker.

  3. 开始串流

    Start streaming

    电脑播放的任何声音都会从 HomePod 里出来。

    Anything your PC plays comes out of the HomePods.

    圆点变绿 = 已同步Green dot = in sync

使用须知Good to know

开始之前

Before you start

首次运行First run
exe 没有代码签名，Windows SmartScreen 可能会拦截：更多信息 → 仍要运行。
The exe is not code-signed, so Windows SmartScreen may ask: More info → Run anyway.
HomePod 权限HomePod access
“家庭”App → 家庭设置 → 扬声器与电视 → 同一网络上的任何人，不设密码。
Home app → Home Settings → Speakers & TV → Anyone on the Same Network, no password.
防火墙Firewall
Windows 询问时允许本程序使用专用网络。圆点变红表示 HomePod 连不回电脑。
Allow the app on private networks when Windows asks. A red dot means a HomePod cannot reach your PC.
延迟Latency
AirPlay 必须有缓冲。自动档会按 Wi‑Fi 状况把它压到最小，总延迟约 150 ms。
AirPlay needs a buffer. Auto keeps it as small as your Wi‑Fi allows, about 150 ms in total.
电脑音箱PC speakers
会同时出声。请在设备本身上调小：Windows 音量也会改变串流的音量。
They keep playing. Turn them down on the device itself: the Windows volume also changes what is streamed.
设置Settings
音源设备、缓冲（自动或固定）和语言（中文 / English）。
Source device, buffer (Auto or fixed) and language (中文 / English).
测试环境Tested with
已在 Windows 11 上用 HomePod mini 测试。
HomePod mini on Windows 11.
